# Introduction

Numerous studies have indicated a decline in cardiorespiratory fitness (CRF) over the years. This study aims to examine whether this decline in CRF directly affects running performance, particularly in long-distance events. By analyzing running performance across different percentiles (90th, 50th, and 10th), this research seeks to offer insights into how CRF decline may influence performance in various competitive levels. Using data from major road race Tely 10, spanning 1995 to 2020, this study examines running speeds and calculates predicted VO₂max as a performance indicator.


# Data Collection

The data collection method employed in this study is web scraping, a process that involves automatically extracting data from web pages. This technique allows for the efficient gathering of large volumes of data from websites. The extracted data, initially unstructured and in HTML format, is subsequently converted into structured data in a spreadsheet or database. Web scraping can capture all data from a website or target specific information as needed by the user. Some websites explicitly prohibit users from scraping data. This is because scraping can slow down the website or potentially overload the server, causing the website to become unresponsive.
